In [8]:
def regression_metrics(actual, predicted):
    mse = mean_squared_error(actual, predicted)
    return {
        "MAE": mean_absolute_error(actual, predicted),
        "RMSE": np.sqrt(mse),
        "R2": r2_score(actual, predicted),
    }

results = pd.DataFrame([
    {"model": "Mean baseline", **regression_metrics(y_test, baseline_predictions)},
    {"model": "Simple linear", **regression_metrics(y_test, simple_predictions)},
    {"model": "Multiple linear", **regression_metrics(y_test, multiple_predictions)},
])
print(results.round(3))
results.to_csv(WEEK_DIR / "reports/model_comparison.csv", index=False)

D3: Questions and Answers¶

D3a. Residual Pattern¶

Answer: The residual plot helps us check if errors are randomly spread around zero. A curve or funnel shape suggests the model has some problems.

D3b. Five Largest Absolute Errors¶

Answer: The code shows the five predictions with the largest errors. These rows should be checked for unusual values or other possible problems, but not deleted without a reason.

D3c. Near-Zero Mean Residual¶

Answer: A mean residual near zero does not mean the model is good because positive and negative errors can cancel each other.

D3d. Similar MAE but Higher RMSE¶

Answer: A higher RMSE means the model may have some very large errors. This matters when large prediction mistakes are costly or dangerous.
